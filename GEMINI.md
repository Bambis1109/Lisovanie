# Project Overview
C# .NET projekt pre riadenie Lisu a Manipulátora.
Frontend: Avalonia UI (MVVM Toolkit).
Backend: Ixxat CANopen Master API v6.2 (komunikácia s Maxon EPOS4).

# Global Rules
1. Vždy používaj moderný C# (pattern matching, async/await).
2. Na logovanie používaj výlučne `Serilog` (`Log.Information`, `Log.Error`, `Log.Fatal`).
3. Odpovedaj v slovenčine, buď stručný a technicky presný.
4. Pri návrhoch kódu nevypisuj celé súbory, ukáž len zmenené metódy.
